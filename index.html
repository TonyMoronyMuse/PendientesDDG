Conexión con GitHub

Esta copia del espacio de trabajo es el mismo tablero de GitHub Pages: lee el pendientes.json en vivo desde TonyMoronyMuse/PendientesDDG y lo revisa cada minuto, así que cualquier cambio hecho en la plataforma de GitHub se refleja aquí, y viceversa. El botón Guardar y subir al repo sube el pendientes.json directo a ese mismo repositorio con la API de GitHub — sin descargar ni subir archivos a mano. El token se guarda en este navegador para que no tengas que pegarlo cada vez: vive solo en este dispositivo, nunca se sube al repo ni va en el código de la página. Cuando venza, pega el nuevo aquí y queda guardado en su lugar.

Sin conectar: pega tu token y pulsa «Probar conexión». Quedará guardado en este navegador.

¿No tienes token? Créalo en GitHub → Fine-grained tokens: solo el repo PendientesDDG, permiso Contents: Read and write. Con ese permiso el token solo puede tocar ese archivo del repo. No lo subas nunca a un archivo del repo ni a un archivo compartido por enlace: cualquiera con el enlace podría leerlo y escribir en tu tablero.
