Conexión con GitHub

El botón Guardar y subir al repo sube el pendientes.json directo a tu repositorio con la API de GitHub — sin descargar ni subir archivos a mano. Al abrir la página en cualquier dispositivo, el tablero se carga solo desde ese archivo, y la exposición lo revisa cada minuto. El token se guarda en este navegador para que no tengas que pegarlo cada vez: vive solo en este dispositivo, nunca se sube al repo ni va en el código de la página. Cuando venza, pega el nuevo aquí y queda guardado en su lugar. Y si hay un archivo token.ddg junto a la página, al entrar al admin la página lo lee y usa ese token sin pedirlo.

Sin conectar: pega tu token y pulsa «Probar conexión». Quedará guardado en este navegador.

¿No tienes token? Créalo en GitHub → Fine-grained tokens: solo el repo PendientesDDG, permiso Contents: Read and write. Con ese permiso el token solo puede tocar ese archivo del repo. También puedes crear un archivo token.ddg junto al index.html con solo el token dentro: al entrar al admin la página lo lee y lo usa sin pedirlo. Ojo: quien pueda abrir ese archivo puede leer el token, trátalo como la llave del repo.
